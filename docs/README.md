# Working Groups — documentation

Index of the **living founding documents** of the Active Inference Institute
Working Groups initiative. These files are the working versions of the
appendices to the position paper *Coordinating the Field: The Case for
Ecosystem-Level Technology Roadmapping and Community Working Groups in Active
Inference* (Version 1.0.0, [doi:10.5281/zenodo.23066904](https://doi.org/10.5281/zenodo.23066904)).
The fixed published snapshot lives in [`../paper/`](../paper/); later changes
land here and are recorded in the commit history.

## Status

The Working Group Charter and Operating Procedures are **drafts for community
review**; the Predecessor Governance Documents and Resources is a reference
bibliography. The drafts carry no force until adopted at the Charter Development
Session of the 6th Applied Active Inference Symposium (online, 12–13 November
2026) and ratified within 90 days afterward. Two further documents referenced by
the Charter are not yet published: the **Domain Working Group Charter Template**
(Charter §10.3) and the **AII Intellectual Property Policy, AII-POL-IP-001**
(Charter §8.5).

## How these documents change

- Comment on a provision by [opening an issue](https://github.com/ActiveInferenceInstitute/Working_Groups/issues/new)
  naming the document and section (for example `Charter §3.4`).
- Concrete wording proposals may be opened as pull requests against this
  directory. A merged editorial fix (typos, links, formatting) does not change
  meaning; substantive change follows the adoption process in the Charter.
- See [`../CONTRIBUTING.md`](../CONTRIBUTING.md) for the full process.
